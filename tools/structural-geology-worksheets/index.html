Structural geology practice problems with worked solutions

Random stereonet, map, stress and identification problems with worked solutions, printable worksheets with answer keys, bubble answer sheets and a grader.

Open the practice problems and worksheets

Topics

  • Stereonet: poles, intersections, angles between lines, apparent dip, true dip from two apparent dips, rake, fold axis from two limbs
  • Maps, folds and faults: notation, three-point problems, true thickness, depth, interlimb angle, fault slip components
  • Stress: Mohr circle, Coulomb failure
  • Identification: thin-section minerals, sedimentary structures, a concepts quiz

For instructors

Every worksheet has a set code that rebuilds the same problems and key. Multiple-choice sets print with a bubble answer sheet, and the grader turns pasted answers into scores, per-question percentages and a CSV.
